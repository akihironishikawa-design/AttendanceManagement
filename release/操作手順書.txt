========================================================================
 勤怠締め処理支援システム(PoC版)  操作手順書
                                              2026年8月29日
========================================================================


■ 1. 締め作業の流れ
------------------------------------------------------------------------

  ① シフト表と打刻データを読み込んで[突合実行]
  ② [出席記録レポートを出力](提出用・確認用)
  ③ [申請書出力へ] で、提出が必要な方の申請書を出力して印刷
  ④ 申請書を対象の方に記入していただき、回収
  ⑤ 回収した申請書のとおりに、画面で勤怠を修正
  ⑥ ⑤で修正した日だけを「勤怠管理簿」に出力
     あわせて[出勤簿を出力][給与計算表を出力]

  ①〜②は毎月必ず、③〜⑥は差異があった方の分だけの作業になります。


■ 2. 画面の構成
------------------------------------------------------------------------

  上段    シフト表・打刻データの指定、対象年月、マスタの編集、設定/ヘルプ/終了
          (Excel ファイルは画面のどこにドラッグ＆ドロップしても取り込めます)
  中段    突合の結果(対象人数・明細件数・正常・時間外・遅刻・早退・早出・要確認)
          と、出力ボタン
  下段    5つのタブ
            出席記録レポート(編集可)  … 一覧の確認と修正
            突合結果                  … 明細の一覧(絞り込み用)
            氏名未解決                … 突合できなかった氏名
            申請書出力                … 申請書の対象者とチェック
            処理ログ                  … 読み込み・出力の記録


■ 3. 突合の実行
------------------------------------------------------------------------

  1. 「シフト表」に .xls / .xlsx を指定します
     ・[参照...]から選ぶか、画面にドラッグ＆ドロップします
     ・シートは自動で選ばれます。違う場合は右の「シート」で変更してください

  2. 「打刻データ」も同じように指定します

  3. [突合実行]を押します

  ・対象年月は、シフト表のシート名や中身から自動で判定します。
    自動判定を外して、手で選ぶこともできます。
  ・「シフト表に載っている社員のみ対象にする」を外すと、打刻だけがある方も
    一覧に出ます(退職者・応援など)。
  ・集計期間は暦月(1日〜末日)のみです。


■ 4. 「出席記録レポート(編集可)」タブ
------------------------------------------------------------------------

  ● セルの見方(1人1行・1日4段)

      1段目  予定シフト(勤務区分の文字、または予定開始時刻)
      2段目  打刻1回目
      3段目  最終打刻
      4段目  状態(遅 / 早 / 早出 / 打刻漏れ / 要確認 / -)

  ● 色

      赤系    打刻漏れ・入力異常など、そのままでは提出できない日
      黄系    要確認(公休や有給の日に打刻がある など)
      紫系    早出
      緑系    遅刻・早退
      グレー  対象外(休場日など)
      白      正常、および時間外

      カーソルを合わせると、理由が出ます。

      ※ 時間外は色を付けません。画面上段の「時間外」の件数だけで確認します。
         提出する書類にも記載しません。

  ● 絞り込み(一覧の上の行)

      「全て」「打刻データなし」「色付きセル」で切り替えられます。
      氏名・部門・社員番号での検索もできます。
      1ページの表示件数は 10 / 20 / 30 / 50 / 100 から選べます(既定 30)。

  ● セルの編集(ダブルクリック、または Enter / F2)

      ・勤務区分            公・有・欠・出張 などから選びます
      ・シフトの開始/終了   時刻を直せます
      ・備考                修正の理由を残せます(申請書の「理由」に出ます)
      ・打刻(実績)         そのままでは直せません。
                            [申請書提出確認済み]を押すと直せるようになります

      申請書を回収してから打刻を直す運用のため、このボタンを押した記録として
      備考に「申請書提出確認済み」が自動で入ります。
      直した内容はその場で判定し直され、青文字になります。

  ● 修正の履歴

      誰がいつ何をどう直したかは自動で記録され、保留ファイルに残ります。


■ 5. 出力ボタン(画面中段)
------------------------------------------------------------------------

  [出席記録レポートを出力]  画面の内容(修正後)をそのまま出力します
  [出勤簿を出力]            勤務区分の月間一覧を出力します
  [給与計算表を出力]        パート・アルバイトの給与計算表を出力します
  [申請書出力へ]            申請書出力タブへ移ります

  ・出力先は「シフト表と同じフォルダ」の中に作る「年月_日時」フォルダです
    例) 202607_20260829_121201\出勤簿_202607.xls
  ・出力が終わるとフォルダが開きます
  ・様式(ひな形)はアプリに同梱しているため、指定は不要です

  ● 出席記録レポートの形

      1人につき4行で出力します。

        1行目  作業番号 / 名前 / 部門
        2行目  シフト(勤務区分の文字、または予定開始時刻)
        3行目  打刻(タイムレコーダーの原文のまま)
        4行目  状態(遅 / 早 / 早出 / 打刻漏れ / 要確認)

      状態を書いた日は、その日の3行を黄色で塗ります。
      正常な日と時間外の日は、状態を書かず、塗りもしません。
      並び順・氏名・部門は打刻データに合わせています。


■ 6. 「申請書出力」タブ
------------------------------------------------------------------------

  提出が必要な方を、申請書ごとに一覧にします。

      タイムカード修正届出書    打刻漏れ・打刻過多・休暇日の打刻
      年次有休休暇・欠勤申請書  有給・欠勤・特別休暇
      出張届                    終日出張・半日出張
      勤怠管理簿                画面で修正した日(⑤のあと)

  1. 申請書を選ぶと、対象者の一覧が切り替わります
  2. 一番左の「出力」チェックで、出す方を選びます(既定は全員オン)
  3. [チェックした申請書を出力]を押すと、
     いま選んでいる申請書だけを1つの Excel ファイルに出力します

  ・タイムカード修正届出書 / 年次有休休暇・欠勤申請書 / 出張届 は
    1シートに2枚並びます。3枚以上のときは2枚ずつ下に足します。
  ・勤怠管理簿だけは 1人1シート で、画面で修正した日だけを書きます。
    セルを直すたびに件数が変わります。
  ・時間外は申請書の対象にしていません。


■ 7. 作業を中断して、続きから再開する(保留)
------------------------------------------------------------------------

  [保留(作業途中を保存)]
      編集中の内容と修正履歴を「作業データ\勤怠突合状況.xlsx」に保存します。
      保存先は聞きません。上書き前の内容は .bak として1世代残ります。

  [保留を開く]
      保存した内容から再開します。保留ファイルがあるときはオレンジ色になります。
      再開時は、そのときのマスタで判定し直します
      (保留中にマスタを直した内容が反映されます)。

  [編集を元に戻す]
      保留したあとの編集を捨てて、保留した時点に戻します。

  ※ この3つのボタンは、一覧の上の行の右端にあります。


■ 8. 氏名が一致しないとき(氏名未解決)
------------------------------------------------------------------------

  シフト表に「平山 部長」、打刻データに「平山 恵亮」のように書かれていると、
  同じ方だと判断できません。この場合は「氏名未解決」タブに出ます。

  1. 「氏名未解決」タブで、対象の行をダブルクリックします
  2. 正式氏名(打刻データの氏名)を選んで登録します
  3. 自動でもう一度突合されます

  ・空白の全角/半角の違いだけなら、登録しなくても自動で解決します
  ・登録内容は「マスタを編集」の「社員名 別名」タブでも直せます


■ 9. マスタ(設定)の編集
------------------------------------------------------------------------

  [マスタを編集]から、8つのタブすべてを画面で設定できます。
  [保存]を押すと masters フォルダに書き込み、次の[突合実行]から反映されます。
  8ファイルまとめて保存し、入力に誤りがあるときは1件も書き込みません。
  上書き前の内容は同じ場所に .bak として残ります。

      社員名 別名     氏名の対応づけ
      勤務区分        公・有・欠・出張 などの意味
      所定労働時間    所属部別・時期別の1日の所定労働時間と休憩
                      予定終了 = 予定開始 + 所定労働時間 + 休憩
                      休憩は「所属部 × 期間 × 平日/土日祝」の3つで決まります
      従業員          管理区分・氏名(必須)・所属部(必須)・所属課・雇用区分・部門・
                      1日の拘束時間・基本時給・入社日・退職日
      祝日            祝日と休場日。毎年同じ日で運用するため「月/日」で登録します
      判定閾値        早出・時間外とみなす分、遅刻早退の許容
      休憩ルール      打刻の丸め方と、拘束時間ごとの休憩
      申請書の対応    判定 → 必要な申請書

  ● 管理区分(勤怠管理の対象を絞る) … 従業員タブ

      従業員タブの一番左に「管理区分」のチェックがあります。
      チェックを付けた方だけを、突合結果の一覧と帳票の対象にします。
      チェックを外した方は、シフト表や打刻データに載っていても対象外です。

      チェックを外すとその行は一覧から消えます。付け直すときは
      [対象外も表示]にチェックを入れてください。
      [全てのチェックを外す]を押すと全員のチェックが外れ、一覧は自動で
      [対象外も表示]に切り替わります。対象にする方を選び直すときに使います。

      ※ 保存する前なら[読み直す]で元に戻せます。

  ● 休憩の決まり方(所属部 × 期間 × 平日/土日祝) … 所定労働時間タブ

      上の一覧(所属部)   … その所属部の「既定の休憩」。期間で入れていない日に使います
      下の一覧(期間)     … その期間だけの休憩。空欄にすると上の既定を使います

      休憩が時期で変わらない所属部は、これまでどおり上の一覧だけ入れれば十分です。

  ● 予定終了時刻(早退・時間外の基準)の決まり方

      1. 画面でシフトの終了時刻を直した場合 … その値
      2. パート・アルバイト               … 予定開始 + 従業員マスタの「1日の拘束時間」
      3. 正社員                           … 予定開始 + 所定労働時間 + 休憩
                                            (所属部と時期で変わります)
      4. 上のどれも決まらない場合         … 予定開始 + 判定閾値マスタの拘束時間

      所属部は従業員マスタの値で引き当てます。
      シフト表や打刻データに書かれている部門ではありません。


■ 10. 勤務時間と休憩の自動計算
------------------------------------------------------------------------

  給与計算表のために、打刻を15分単位に丸めてから計算します。

      15分丸め → 拘束時間(丸めた退勤 − 丸めた出勤) → 休憩 → 実労働時間

      拘束6時間以内          休憩 15分
      拘束6時間超〜8時間以内  休憩 45分
      拘束8時間超            休憩 1時間30分

  ・丸めは現在「出勤=切り上げ / 退勤=切り捨て」です(要確認 1章)
  ・画面の一覧・出席記録レポート・遅刻早退の判定には、丸めない実打刻を使います


■ 11. 困ったときは
------------------------------------------------------------------------

  ● 突合実行が押せない
      シフト表と打刻データの両方が指定されているか確認してください。

  ● 「氏名未解決」がたくさん出る
      役職表記の氏名です。8章の手順で登録してください。

  ● 「日番号(1,2,3...)が並ぶ行を検出できません」と出る
      集計期間が暦月でないシート(6.16-6.30 など)は読み取れません。
      月ごとのシートを選んでください。

  ● 出力したファイルが開けない・数字が0のまま
      Excel で開き直すと再計算されます。
      それでも直らない場合は「処理ログ」タブの内容をお知らせください。

  ● 起動しない・エラーが出る
      「処理ログ」タブの内容と、操作した手順をお知らせください。

  ● 元のシフト表・打刻データが書き換わることはありません
      読み取りだけを行い、出力は別のフォルダに作ります。
